# Test handoff — 타이머 기록 UI

## Summary
타이머 기록 **달력 / 날짜 목록 / 세션 상세**를 편하게 다시 짰습니다. 날짜에 세션 수, 시간·세션·랩 칩, 큰 세션 카드, 랩별 기구 칩.

## Test focus
1. 달력: 이전/다음 달, 오늘, 기록 있는 날에 세션 수
2. 날짜 선택 → 총 시간 / 세션 / 랩 칩 + 세션 카드(시간대, 큰 운동시간)
3. 빈 날짜 → 안내 + 타이머 열기
4. 세션 상세 → 달력으로, 랩 시간·기구 칩, 기구 탭 시 상세 이동

## As-is → To-be
- as-is: 긴 문장 메타, 점만 있는 달력, 빈약한 카드
- to-be: 세션 수 달력, 통계 칩, 큰 시간 카드, 랩 기구 칩
