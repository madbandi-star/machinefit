# MachineFit i18n — 운영 가이드

지원: **ko / en / ja / zh**

## 구조

```
frontend/src/i18n/
  index.ts                 # fallbackLng: current → en → ko, missing-key warn (dev)
  locales/{ko,en,ja,zh}/*.json
  overlays/                # ja/zh quality overlays for common UI
scripts/i18n-audit.mjs     # build-time key parity
scripts/i18n-deep-merge.mjs
```

Namespaces: `common`, `machines`, `gyms`, `community`, `notifications`, `admin`, `trade`, `online-pt`, `push`, `friends`, `equipment`

## Fallback

1. 현재 언어  
2. 영어 (`en`)  
3. 한국어 (`ko`)  

`returnEmptyString: false` — UI에 빈 문자열 금지.

## 최초 언어

1. 저장된 설정 (`machinefit-settings.locale`)  
2. (최초) 브라우저 언어  
3. 한국어  

언어 변경 시 `ensureLocaleResources` + `changeLanguage` → **새로고침 없이** 즉시 반영.

## 개발 / 운영

| 환경 | Missing key |
|------|-------------|
| DEV | `console.warn([Missing Translation] …)` |
| PROD | 경고 없음, fallback 적용 |

## 빌드 검사

```bash
npm run i18n:audit          # 누락 시 exit 1
npm run i18n:sync           # en 기준으로 누락 키 채움
```

`frontend` / root `build` 에 audit 포함.

## DB 다국어

- **Catalog (기구·브랜드·팁 등):** JSONB `LocalizedString` `{ ko, en, ja, zh }`
- **CMS형 콘텐츠:** `content_translations` (migration `101`) — notices/FAQ 확장용
- Resolve: FE `getLocalizedName` / BE `pickLocalized` — locale → en → ko → any

관리자: `LocalizedStringFields` 컴포넌트로 4개 언어 동시 편집.

## 날짜·숫자·통화

`frontend/src/utils/localeFormat.ts`

- `formatLocaleDate` / `formatLocaleNumber` / `formatLocaleCurrency`

## API 오류

Backend `AppError.code` → FE `apiErrorCatalog.ts` → `common:errors.*`  
서버 prose보다 **에러 코드 매핑을 우선**.

## 헬스 용어

기구명은 현지 관용 + 영문 관용어 병행 (Chest Press, Lat Pulldown 등).  
ja/zh catalog 네임스페이스는 우선 en 기반(기구 영문명 유지) + UI 오버레이로 품질 보강.

## 언어 추가 (es/de/fr)

1. `LOCALES`에 코드 추가  
2. `frontend/src/i18n/locales/<code>/` 에 ko와 동일 네임스페이스 생성 (`npm run i18n:sync` 확장)  
3. `fallbackLng`에 `['en','ko']` 등록  
4. overlay로 UI 품질 번역  
→ 구조상 확장 가능.
